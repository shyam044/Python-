Displaying the output

To display output, we use print(). Start with the classic Hello World example and then run it yourself.

To display the output, we use print()

The Python print() function sends the value inside the parentheses to the program output.

Python
print("Hello World")

You can replace "Hello World" with other text, numbers, variables, or expressions that you want Python to display.
